# Dongmin Ethan Kang – Professional Website

Welcome to my personal portfolio and professional website. This is a clean, minimalist web presence showcasing my work and expertise.

## About Me

I'm Dongmin Ethan Kang, a professional focused on creating elegant solutions and sharing knowledge. This website serves as a hub for my professional information, projects, and insights.

## Website Design

This website is built with simplicity and performance in mind:

- **Clean Architecture:** Pure HTML, CSS, and minimal JavaScript – no frameworks, databases, or complex backends required
- **Fast & Lightweight:** Optimized for speed and accessibility across all modern devices
- **Responsive Design:** Works seamlessly on desktop, tablet, and mobile
- **Language Composition:**
  - TeX (60.1%) – for technical documentation and typesetting
  - HTML (29.3%) – semantic markup
  - CSS (7%) – styling and layout
  - Python (2.8%) – utility scripts
  - JavaScript (0.8%) – minimal interactivity

## Getting Started

To view or work with this site locally:

- **VS Code + Live Server:** Right-click `index.html` → "Open with Live Server"
- **Python Server:** Run `python -m http.server 8000` in the project folder
- **Live Online:** Visit the deployed site via GitHub Pages
